# Institute 9

Phase 1: lightweight premium landing-screen frontend.

## Local preview

Requirements: Node.js 20+

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173

## Build

```bash
npm run build
npm run preview
```

This first phase intentionally contains only the header and hero screen. The application will be expanded step-by-step without bringing unrelated repository code into this project.
